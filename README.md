# Beecrowd 1071 - Soma de Ímpares Consecutivos I

## Descrição

Este programa resolve o problema 1071 do Beecrowd, que consiste em ler dois valores inteiros X e Y e calcular a soma dos números ímpares que estão entre eles.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

O programa recebe dois valores inteiros X e Y.

## Saída

O programa deve imprimir a soma dos valores ímpares que estão entre os valores fornecidos na entrada.
